# Third-party sources

## Scam Sniffer public domain database

- Maintainer: Scam Sniffer
- Source: https://github.com/scamsniffer/scam-database
- Runtime data: https://raw.githubusercontent.com/scamsniffer/scam-database/main/blacklist/domains.json
- License: GNU General Public License v3.0, https://github.com/scamsniffer/scam-database/blob/main/LICENSE
- The database's documentation states that public data has a 7-day delay. It is queried at runtime and cached in memory; source code and bulk data are not bundled here. Evidence exports include source attribution, license name, retrieved time and matched domain entries. If distributing a database snapshot or modified dataset, preserve upstream notices and provide its corresponding source/license under the applicable terms.

## Public information providers

Wallet and NFT index: Blockscout Ethereum public API. Chain reads: configured Ethereum RPC. Project text: independently configured official project entry points. Availability, index lag and content changes can affect results. No provider reputation field is treated as a guarantee of asset safety.
